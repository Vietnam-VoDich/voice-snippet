# Voice Snippet Launch Copy

## LinkedIn Post Draft

I built Voice Snippet because I wanted a faster way to capture thoughts while working.

It is a tiny Mac app that sits in the menu bar. Press a shortcut, speak, and it transcribes your voice locally. The transcript goes straight to your clipboard, and you can clean it up into notes, bullets, or an email with on-device Apple Foundation Models.

What I care about most:

- Local-first by default
- No account
- No API keys
- No cloud transcription
- Open-source code

It is Mac-only for now: Apple Silicon, macOS 26+, and Apple Intelligence for the rewrite styles. That is a narrow first version, but it is real, useful, and something I use myself.

GitHub: https://github.com/Vietnam-VoDich/voice-snippet

If you try it, I would love feedback on the workflow, the install experience, and what you would want from a Windows or older-macOS version.

## Short Demo Script

1. Open with the floating Voice Snippet pill visible.
2. Say: "I am sharing Voice Snippet, a local-first Mac app for turning rough voice notes into clean text."
3. Stop recording and show the transcript.
4. Use one rewrite style.
5. Paste the cleaned result into Notes or LinkedIn.
6. End on the GitHub release page.
